# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful. Disagree about the work, not about the person.
- Assume good faith, and say plainly when something is wrong.
- No harassment, insults, or personal or political attacks, in issues, pull requests or anywhere else the project is discussed.
- Do not publish anyone's private information.

## Scope

This applies in the repository's issues, pull requests and discussions, and wherever someone is representing the project.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub: https://github.com/rahul05ranjan. Reports are read and kept confidential. The maintainer may remove comments, close threads, or block an account that does not follow this code.
